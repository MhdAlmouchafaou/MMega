# MMega

Économiseur de données et testeur de connexion pour Android.

- Consommation exacte par application (mobile / Wi‑Fi, premier plan / arrière-plan)
- Suivi du forfait : solde en direct, prévision d’épuisement, alertes, coupure automatique
- Pare-feu sans root (VPN local) : blocage par app, mode Éco, coupure écran éteint
- Vitesse en temps réel dans la barre d’état
- Test de débit (ping, gigue, réception, envoi, latence en charge), diagnostic, infos réseau

L’APK est compilé par GitHub Actions et publié dans les Releases.
